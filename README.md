# nokako

Nostr の投稿やリアクションを監視し、指定したキーワードや特定クライアントからの投稿を通知するボットクライアント（Windows デスクトップアプリ）です。

---

## 動作環境
- **OS**: Windows 10 / Windows 11 (x64)
- **ランタイム**: [.NET 8.0 ランタイム (Desktop Runtime)](https://dotnet.microsoft.com/download/dotnet/8.0)

---

## 主な機能

- **通知ボット機能**:
  - 指定したキーワードを含む投稿や特定クライアントからの投稿を検知し、通知先（あなた）宛てにリプライ通知を送信
  - 連続投稿制限機能（過度なリプライを防ぐため、同一種別の通知は最短60秒間隔で送信）
- **検知対象**:
  - **キーワード検知**: あらかじめ登録したキーワードを含むテキストノート（kind: 1）
  - **nokakoiファミリー検知**: `client` タグに `kakoi`、`nokako`、`nokakoi`、`kako` が含まれる投稿
  - **自分宛てリアクション**: ログインユーザー宛てのリアクション（kind: 7）を検知してグリッド上にハイライト表示
- **インデクサリレー連携**:
  - プロフィール未取得のアカウントもインデクサリレー（`directory.yabu.me`）から非同期に自動取得し、グリッドの表示名を動的に更新
- **ボット遠隔コマンド**:
  - 通知先（あなた）のアカウントからボット宛てに特定のキーワードを投稿することで、ボットの動作をリモート制御可能
- **通知時アクション**:
  - Windows のバルーン（トースト）通知表示
  - 検知時に指定した URL / クライアントでイベントを自動オープン
- **タスクトレイ常駐**:
  - 最小化時にタスクトレイへ格納し、バックグラウンドで監視を継続

## 操作方法・ショートカット

| 操作 | 動作 |
|---|---|
| **Start ボタン** | リレーへの接続を開始し、タイムラインおよび通知の監視を開始します |
| **Stop ボタン** | 監視を停止してリレーから切断します（最新のプロフィール情報を保存） |
| **Relay ボタン** | 接続先リレーの追加・削除・有効/無効を設定する画面を開きます |
| **Setting ボタン** / `ESC` | 基本設定画面（ボットの nsec、通知先、nokakoiクライアント検知、不透明度等）を開きます |
| **余白右クリック** / `F10` | マニアック設定画面（キーワード一覧、通知先 npub、バルーン通知、外部アプリ起動、ユーザー管理等）を開きます |
| **リレー情報ラベル（画面下部）** | ホバーで各リレーの接続ステータス（接続中 / ❌ 切断）をツールチップ表示します |
| **トレイアイコン左クリック** | ウィンドウの最小化 / 表示切り替えを行います |
| **トレイアイコン右クリック** | コンテキストメニュー（Setting / Quit）を開きます |

## 使い方

1. **ボット用アカウントの準備**:
   - ボット動作用の Nostr アカウント（nsec）を用意します（ブラウザのプライベートウィンドウ等で Nostr クライアントを開いて新規作成すると手軽です）。
2. **基本設定（`ESC` または Setting ボタン）**:
   - ボットアカウントの秘密鍵（`nsec1...`）を入力して保存します（秘密鍵は Windows 資格情報マネージャーにより暗号化されて安全に保管されます）。
3. **通知設定（`F10` または 余白右クリック）**:
   - 通知先となるあなた自身の公開鍵（`npub1...`）を入力します。
   - 監視したいキーワードを1行に1つずつ入力します。
   - 必要に応じてバルーン通知や外部アプリ/ブラウザ起動（URL）を設定します。
4. **監視開始**:
   - **Start** ボタンを押してリレーへ接続します。条件に一致する投稿が流れると、グリッドに表示されるとともにボットからあなた宛てに通知リプライが送信されます。

## ボット制御コマンド（遠隔操作）

通知先に指定されているあなたのアカウントからボット宛てに以下の文字列を投稿することで、ボットを遠隔操作できます：

| コマンド | 動作 |
|---|---|
| `on` | ボットからの通知投稿を有効化します |
| `off` | ボットからの通知投稿を一時停止します（監視ログの受信は継続されます） |
| `去年` | 去年の同日の投稿を表示する nostter リンクを返信します |
| `昨日` | 昨日の投稿を表示する nostter リンクを返信します |

## 各種設定ファイル

アプリの実行フォルダ内に以下の設定ファイルが保存されます：
- `nokako.config`: ウィンドウ位置、不透明度、基本オプション設定（XML形式）
- `relays.json`: 接続先リレー情報
- `users.json`: ユーザープロフィール情報のキャッシュ（表示名、petname、ミュート設定等）
- `keywords.json`: 監視キーワード、通知先 npub、通知アクション設定（JSON形式）
